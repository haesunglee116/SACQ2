Quantization scope and how bits are counted

L/A bpw is the nominal, parameter-weighted average over the 338 language-backbone and action-head candidate linear layers (112 + 226) and excludes codebook and scale metadata; allocation itself is driven by the calculated storage including that metadata. The remaining 128 linear layers and the token embedding are fixed at 4-bit; activations remain BF16. Memory is the resident footprint of the full loaded policy. The GPTQ series includes a custom ternary extension at log2(3) ≈ 1.585 bpw; the 2- and 3-bpw points use standard GPTQ. “TWLA” is the TWLA-compatible PyTorch port described in the paper. Each configuration uses 500 episodes per LIBERO suite. Latency is whole-model inference latency measured with the official GR00T inference path on an RTX 4090 at batch size 1 with four denoising steps: wall-clock time with GPU synchronization before and after each model call, the median of 20 measurements after five warmup iterations, excluding preprocessing. BF16 uses the same common runtime optimizations and CUDA Graph execution as the SACQ settings.

Abstract

Vision-Language-Action (VLA) models enable capable robot behavior, but their large memory footprint limits deployment on resource-constrained robotic platforms. Weight quantization is a natural remedy, yet post-training quantization (PTQ) recipes inherited from large language models degrade when applied to VLAs at ultra-low precision. Existing low-bit PTQ methods often fail to explicitly account for the structure of downstream operations and allocate precision without considering its effect on the policy actions. We introduce SACQ, an ultra-low-bit weight-only vector-codebook quantization framework for VLAs. SACQ combines (1) structure-aware codebook fitting with role-specific quadratic metrics that reflect input statistics and downstream sensitivity; (2) action-aware mixed-bit allocation based on the increase in final-action error as individual layers are compressed; and (3) two-stage post-quantization refinement that reassigns codeword indices with second-order error compensation and calibrates codebooks and row-group scales against the decoded action. Using GR00T N1.7, SACQ achieves 93.85% average success across four LIBERO suites at 1.5 bits per language/action weight while reducing model memory by 4.83×. With INT8 activation quantization and low-precision attention, it retains 93.55% success while running 1.51× faster than BF16. On SimplER, SACQ further achieves 63.76% and 52.27% success under Visual Matching and Variant Aggregation at 2 bits per language/action weight, compared to 58.90% and 53.45% for BF16, respectively.

Method

SACQ uses a block-scaled vector-codebook representation: weights are split into row groups of g = 64 entries normalized by their own scale, grouped into d = 4-dimensional vectors, and each vector stores one index into a single per-layer codebook. Its three components connect the local structure of each projection to the action produced by the full policy.

1

Structure-aware codebook fitting

Fitting a codebook means choosing codewords and assignments that minimize a distortion over all vectors. Euclidean distance treats every coordinate alike; SACQ instead measures each vector’s error with its own positive semidefinite matrix G(v), which encodes which errors to accept and which to avoid, under a per-vector weight α(v) ≥ 0:

min𝒞,a ∑v∈𝒱 α(v) (v−ca(v))⊤ G(v) (v−ca(v))

Setting α(v) = s(v)2 would weight each vector by its block scale in the original weight space; SACQ sets α(v) = 1 and fits directly in the scale-normalized space. The metric is derived from the operation that consumes each projection, not from the projection output itself. For a query projection, the error is measured at the attention logits, which introduces an output-side weighting from the keys; the key projection mirrors it. Value errors are weighted by the attention probabilities and the output projection. Gate and up projections pass through SwiGLU and the down projection, giving first-order diagonal sensitivities. To keep fitting separable, SACQ keeps the diagonal of the output-side weighting and the 4×4 input block of the vector:

G(v)= Br(v),r(v) AI(v),I(v)

Here A is the input-side Gram and B the output-side weighting of the role. The DiT action head follows the same principle with separate query- and key/value-side statistics in cross-attention, GELU feed-forward sensitivities, and an output-side weighting for AdaLN modulation. Given G(v), the codebook is optimized by alternating metric-weighted assignment and weighted least-squares codeword updates.

2

Action-aware mixed-bit allocation

Each candidate layer moves through a chain of states ordered by precision, GPTQ (4bit) → GPTQ (3bit) → VC (2.75bit) → VC (2.5bit) → ⋯ → VC (1bit), where VC (rbit) is a vector-codebook state with nominal rate r bits per weight and codebook size 2dr; the 1-bit operating point additionally allows VC (0.75bit). Only transitions between adjacent states are allowed. For each layer ℓ, SACQ measures Δℓ, the increase in final-action relative error when that layer alone is moved one state down, by actually running the policy on the calibration set with equal weighting across suites.

Storage is counted as calculated bits per weight including codebooks and row-group scales, since this overhead is not negligible at low rates. At each greedy step, SACQ selects the component (language backbone or action head) with the higher calculated bits per weight and, within it, the layer with the smallest action-error increase per bit saved:

ℓ⋆= argminℓ Δℓ costℓ(sℓ)−costℓ(sℓ′)

This component-balancing rule prevents either part of the policy from being compressed disproportionately. Sensitivities are refreshed every 100 accepted moves, so the procedure is a periodically refreshed greedy search rather than a globally optimal allocation.

3

Two-stage post-quantization refinement

Both stages apply only to vector-codebook layers; layers that remain in GPTQ states are kept fixed. The two mechanisms play different roles: G(v) guides projection-specific codebook fitting, while index reassignment compensates cross-vector quantization errors.

Index reassignment.

With codebooks, scales, and the bit allocation fixed, SACQ runs the frozen quantized policy on calibration data, collects the input second-moment matrix Hℓ of each target layer, and takes the Cholesky factor Uℓ of its damped inverse. Vectors are reassigned sequentially against the original BF16 weight; the residual of each assignment is propagated to the remaining coordinates so later vectors absorb earlier error:

aJ∗ =argmink‖(w¯J−qk)UJJ−1‖22 w¯R ←w¯R−(w¯J−qaJ∗)UJJ−1UJR

Action-level calibration.

With the updated indices a∗ frozen, only the codebooks C and row-group scales s are optimized so that the quantized policy matches the BF16 action. Keeping the indices fixed preserves the storage rate during calibration:

min𝒞,s 𝔼x [ 1Nx ‖𝐚Q(x;𝒞,s,a∗)−𝐚BF16(x)‖F2 ]

Calibration uses AdamW on 576 training requests per LIBERO suite (64 held for validation) for 12 epochs, selecting the checkpoint with the lowest validation relative action error. The same policy-noise seed is used for the quantized and BF16 policies when computing the loss.

Experiments

We quantize 338 linear layers of GR00T N1.7 (112 language-backbone and 226 DiT action-head layers) while keeping the remaining 128 linear layers and the token embedding at 4-bit; except for the A8 inference setting, activations remain BF16, with BF16 as the full-precision reference. We compare against HQQ, GPTQ, ActQuant, TWLA, and AQLM under the same language/action scope; calibration-based methods use the same calibration data as SACQ and follow their own quantization and optimization procedures. Evaluation uses the four LIBERO suites (500 episodes each, environment seed 17) and the SimplER Google Robot Visual Matching and Variant Aggregation protocols (seed 7). We then measure inference efficiency at W1.5, and check that the behavior carries over to OpenVLA-OFT, a different VLA architecture, and to GR00T N1.7 under the LIBERO-Pro perturbations.

Paper · Table 3

At 1.5 L/A bpw (W1.5), we evaluate two activation-precision settings: a 16-bit activation setting (W1.5A16) and an 8-bit activation setting (W1.5A8). In A8, linear projections use dynamic per-row symmetric INT8 activation quantization with INT8 GEMMs, while action self-attention and vision attention use an INT8-QK/FP8-PV attention path; the attention cores in action cross-attention and language attention remain in BF16. The runtime additionally uses optimized packed-weight decoding kernels and CUDA Graph execution while retaining SACQ’s compressed weight representation. For a fair comparison, BF16 uses the same common runtime optimizations and CUDA Graph execution.

Component ablation on LIBERO

Paper · Table 4
