Abstract

Vision-Language-Action (VLA) models produce remarkably capable robot behavior, but their memory footprint makes deployment on resource-constrained robotic platforms challenging. Weight quantization is a natural remedy, yet post-training quantization (PTQ) recipes inherited from large language models degrade sharply when applied to VLAs at ultra-low precision. Two limitations become particularly important: existing low-bit PTQ methods typically assess quantization error at the layer or projection level without modeling the downstream operation through which it propagates, and allocate precision without directly measuring how reducing a layer’s precision changes the policy action. We introduce SACQ, an ultra-low-bit weight-only vector-codebook quantization framework for VLAs. SACQ combines (1) structure-aware codebook fitting, which fits each layer using a role-specific quadratic metric derived from the operation its projection feeds; (2) action-aware mixed-bit allocation, which assigns precision according to decoded-action degradation as individual layers are compressed; and (3) two-stage post-quantization refinement, which first reassigns codeword indices with second-order error compensation and then calibrates codebooks and row-group scales against the decoded action. On GR00T N1.7, SACQ retains 93.85% average success across all four LIBERO suites at approximately 1.5 bits per language/action weight, only 0.25 percentage points below the 94.10% BF16 reference, while reducing resident model memory from 5.677 GB to 1.175 GB, a 4.83× reduction. On SimplER Google Robot, at approximately 2 bits per language/action weight, SACQ achieves 63.76% and 52.27% success under Visual Matching and Variant Aggregation, respectively, compared with 58.90% and 53.45% for BF16.

Motivation

Which quantization errors matter for action?

Ultra-low-bit quantization creates a tight error budget. Preserving a robot policy requires understanding both where a weight error propagates and how a precision change affects the final action.

01

The projection’s role matters.

A query error perturbs attention logits. A gate error passes through a nonlinearity and interacts with the up projection. Similar projection-output errors can therefore produce different downstream distortions.

SACQ fits codebooks with role-specific metrics derived from those downstream operations.

02

The decoded action matters.

A layer that looks insensitive under a local reconstruction objective can still change the final action. Local error alone does not determine where a VLA can safely lose precision.

SACQ measures action-error changes when each layer moves to a lower-precision state.

Method

Fit the codebooks. Allocate the bits. Refine the policy.

SACQ represents normalized 4D weight vectors with shared codebooks, discrete indices, and row-group scales. Its three components connect the local structure of each projection to the action produced by the full policy.

1

Structure-aware codebook fitting

Instead of treating every projection-output error alike, SACQ constructs a quadratic metric from the downstream operation that consumes the projection. For query and key projections, the metric targets attention-logit distortion. Value projections account for attention weighting and the output projection; feed-forward metrics reflect nonlinear sensitivities and the downstream projection.

The resulting role-specific metric guides both codeword assignment and codeword updates. A separable approximation makes fitting practical, retaining local input correlations where used and output-channel importance. The DiT action head follows the same principle with metrics for cross-attention, GELU feed-forward layers, and AdaLN modulation.

minC,a ∑v (v − ca(v))T G(v) (v − ca(v))
2

Action-aware mixed-bit allocation

Each candidate layer can move through progressively lower-precision states, from GPTQ4 and GPTQ3 to vector-codebook states. SACQ measures the increase in relative decoded-action error caused by a one-step precision reduction, using actual policy outputs on calibration data.

At each greedy step, it first chooses the language or action component with the higher calculated bits per weight, then lowers the layer with the smallest action-error increase per bit saved. Storage accounting includes codebooks, indices, and scales; sensitivities are refreshed periodically as the allocation changes.

Scoreℓ = Δ action errorℓ / bits savedℓ
3

Two-stage post-quantization refinement

First, reassign the indices.

With codebooks, scales, and bit allocation fixed, SACQ uses second-order input statistics from the quantized policy to reassign indices against the original BF16 weights. Sequential error compensation lets later vectors absorb errors from preceding assignments.

Then, calibrate the actions.

With the updated indices fixed, SACQ optimizes only codebooks and row-group scales to match the BF16 policy’s decoded actions. This directly refines action fidelity while preserving the storage rate.
